تم إصلاح المشروع وإكمال نظام الدستور.

المزايا:
1. كتاب دستور بتصميم ورق قديم وتأثير تقليب صفحات.
2. إضافة وتعديل وحذف وإخفاء وترتيب الأبواب.
3. إضافة وتعديل وحذف وإخفاء وترتيب المواد.
4. زر استيراد دستور كامل: الصق النص، والنظام يكتشف الأبواب والمواد ويرتبها تلقائياً.
5. توزيع المواد على صفحات الكتاب تلقائياً، بدلاً من صفحة منفصلة لكل جملة قصيرة.
6. معاينة الكتاب من لوحة التحكم مع نفس الأبواب والمواد.

التشغيل:
- افتح مجلد project في VS Code.
- شغّل: npm.cmd install
- ثم: npm.cmd run dev

قاعدة البيانات:
شغّل ملف الهجرة التالي في Supabase SQL Editor إذا لم تشغله سابقاً:
supabase/migrations/20260802160000_add_constitution_chapters_and_articles.sql

طريقة الاستيراد:
لوحة التحكم > الكتب والدستور > اختر الكتاب > استيراد دستور.
استخدم عناوين مثل: الباب الأول: الدولة والنظام العام
واكتب المواد مثل: المادة (1): هوية المدينة
