المرحلة الأولى: المكتبة القانونية

تم العمل على النسخة الرسمية التي رفعها المستخدم: fivem-rules-site-manageable-tabs.

التعديلات:
1. مكتبة قانونية منظمة بدون تكرار في الواجهة.
2. كتاب واحد فقط لكل نوع:
   - دستور مدينة ساندي
   - العقوبات
   - قوانين الرول بلاي
   - قوانين الشرطة
   - القضاء
   - الإدارة
   - دليل الإسعاف
   - نظام العصابات
3. الدستور أكبر بنسبة بسيطة فقط.
4. الأغلفة أصغر ومسافاتها أوسع.
5. Hover: ارتفاع خفيف، تكبير خفيف، توهج ذهبي، وزر فتح الكتاب.
6. غلاف مستقل لكل كتاب، وغلاف الرول بلاي مختلف عن الشرطة.
7. فتح الكتب داخل قارئ واحد مع السابق والتالي والبحث والفهرس.
8. إصلاح كود قارئ الكتب الأصلي الذي كان يحتوي CSS مكتوبًا خارج وسم style ويسبب أخطاء JSX.
9. لم يتم تعديل Supabase أو إضافة سجلات أو Migrations في هذه المرحلة.

ملاحظة الاختبار:
تم فحص App.tsx بمترجم TypeScript ولم تظهر أخطاء Syntax.
لم يكتمل npm install داخل بيئة ChatGPT بسبب نقص حزمة في مستودع npm الداخلي، لذلك يجب تشغيل npm install ثم npm run dev على جهاز المستخدم للاختبار النهائي.
