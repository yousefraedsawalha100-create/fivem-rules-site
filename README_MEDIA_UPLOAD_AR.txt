ميزة رفع الصور والفيديو
========================

تمت إضافة رفع الملفات مباشرة من الجهاز في:
1. شعار السيرفر.
2. غلاف الكتاب.
3. صورة صفحة الكتاب.
4. الصور والفيديو في قسم المحتوى.

قبل الاستخدام:
1. افتح Supabase > SQL Editor > New query.
2. شغّل محتوى الملف:
   supabase/migrations/20260802180000_create_site_media_storage.sql
3. بعد نجاح SQL، افتح الموقع وجرب رفع ملف من لوحة التحكم.

الحدود:
- الصور: JPG, PNG, WebP, GIF حتى 10MB.
- الفيديو: MP4, WebM حتى 100MB.

للنشر:
git add .
git commit -m "Add direct media uploads"
git push origin main

ملاحظة أمنية:
المشروع الحالي يستخدم كلمة مرور داخل التطبيق بدل Supabase Auth، لذلك سياسات Storage تسمح للعميل العام بالرفع إلى bucket المخصص. يوصى لاحقًا بربط لوحة التحكم بـ Supabase Auth ثم تشديد سياسات الرفع.
